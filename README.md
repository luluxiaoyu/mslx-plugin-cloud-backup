# MSLX 云端备份同步插件

MSLX 云端备份同步插件可在服务器实例生成备份后，自动将备份文件上传至远端存储，并支持本地与云端备份的自动滚动清理。

## 支持协议

- **S3 兼容对象存储**：AWS S3、Cloudflare R2、MinIO、阿里云 OSS、腾讯云 COS 等
- **WebDAV**：AList、Nextcloud、坚果云、NAS 等
- **FTP / FTPS**：独立服务器、VPS、私有 NAS 等

## 使用方法

### 配置存储策略
1. 打开任意实例详情，进入「云端同步」选项卡。
2. 点击「管理存储策略」，新建策略并选择协议类型（S3 / WebDAV / FTP）。
3. 填入连接信息后点击「测试连接」，测试通过后保存策略。

### 启用同步与保留规则
1. 开启「开启云端自动同步」开关，选择已配置的存储策略。
2. 设置远端存储路径模板（默认 `/mslx-backups/{serverName}/`，支持 `{serverName}`、`{instanceId}`、`{date}` 等变量）。
3. 配置保留策略：
   - **本地备份保留**：可设置为保留指定份数、上传后删除本地文件或不清理。
   - **云端保留份数**：超出设定份数后自动清理最旧的历史备份。
   - **GFS 归档联动**（可选）：若安装了 GFS 备份插件，可单独或同时同步日/周/月长期归档。
4. 点击「保存配置」即可生效。可在下方列表中查看已同步的远端文件并支持手动删除。
